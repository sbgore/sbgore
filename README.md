# Sudhir Gore Portfolio

Static HTML/CSS/JavaScript portfolio.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the folder to a GitHub repository and enable GitHub Pages.

## Before publishing
1. Replace `your.email@example.com`.
2. Replace LinkedIn and GitHub URLs.
3. Put your real resume at `assets/Sudhir-Gore-Resume.pdf`.
4. Review all experience wording and dates.
